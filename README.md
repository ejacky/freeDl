# Video Downloader Chrome扩展

这是Video Downloader的Chrome浏览器扩展部分，用于检测和下载网页中的m3u8视频。

## 功能特性

- 🎬 自动检测网页中的m3u8视频链接
- 🔍 多种检测方式：链接扫描、脚本解析、网络监控
- 📱 现代化用户界面
- ⚙️ 可配置服务器地址和下载路径
- 📊 实时下载进度显示
- 🔄 支持多任务下载

## 安装方法

### 开发者模式安装

1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含 `manifest.json` 的文件夹（即此 `extension` 文件夹）

### 打包安装

1. 在 `chrome://extensions/` 页面点击"打包扩展程序"
2. 选择此 `extension` 文件夹
3. 生成 `.crx` 文件
4. 拖拽 `.crx` 文件到扩展页面安装

## 使用方法

1. **启动服务器**
   - 确保本地服务器正在运行 (http://localhost:3000)
   - 参考 `../server/README.md` 了解服务器启动方法

2. **检测视频**
   - 访问包含m3u8视频的网页
   - 点击Chrome工具栏中的扩展图标
   - 扩展会自动检测页面中的视频链接

3. **开始下载**
   - 在扩展弹窗中查看检测到的视频
   - 点击"开始下载"按钮
   - 查看实时下载进度

## 配置选项

在扩展弹窗中可以配置：

- **本地服务器地址**: 默认 `http://localhost:3000`
- **下载路径**: 默认 `./downloads`

## 文件说明

```
extension/
├── manifest.json      # 扩展配置文件
├── popup.html         # 扩展弹窗界面
├── popup.js           # 弹窗逻辑和UI交互
├── content.js         # 内容脚本，检测页面视频
├── background.js      # 后台脚本，处理扩展消息
└── README.md          # 此文件
```

### manifest.json
扩展的核心配置文件，定义了：
- 扩展权限
- 内容脚本注入规则
- 弹窗页面配置
- 后台脚本配置

### popup.html & popup.js
扩展的用户界面：
- 视频检测状态显示
- 下载进度监控
- 配置选项设置
- 用户交互处理

### content.js
页面内容脚本，负责：
- 扫描页面中的所有链接
- 检测script标签中的视频URL
- 监控网络请求中的m3u8链接
- 检测video元素和iframe内容

### background.js
后台服务脚本，负责：
- 处理扩展消息传递
- 管理标签页状态
- 处理扩展图标点击事件

## 支持的网站

扩展支持检测以下类型的m3u8视频：

- HLS流媒体 (HTTP Live Streaming)
- 各种视频网站的播放列表
- 直播流链接
- 分段视频文件

## 开发指南

### 修改扩展

1. **修改代码后**
   - 在 `chrome://extensions/` 页面点击扩展的"刷新"按钮
   - 或者重新加载扩展

2. **调试**
   - 右键点击扩展图标 → "检查弹出内容"
   - 在扩展管理页面点击"检查视图"

3. **日志查看**
   - 打开Chrome开发者工具
   - 查看Console标签页的日志输出

### 权限说明

扩展需要以下权限：

- `activeTab`: 访问当前活动标签页
- `storage`: 保存用户配置
- `scripting`: 注入内容脚本
- `host_permissions`: 访问所有网站和本地服务器

## 故障排除

### 无法检测到m3u8 URL

这是最常见的问题，以下是详细的解决步骤：

#### 1. 使用调试工具
- 页面右上角会出现"🎬 Video Downloader Debug"调试面板
- 点击"🔍 手动检测"按钮查看详细检测过程
- 查看检测日志了解哪些地方找到了URL

#### 2. 手动重新检测
- 点击扩展图标打开弹窗
- 点击"🔍 手动重新检测"按钮
- 等待检测完成

#### 3. 检查浏览器控制台
- 按F12打开开发者工具
- 切换到Console标签页
- 查看"Video Downloader"相关的日志信息

#### 4. 使用测试页面
- 打开 `test.html` 文件测试扩展功能
- 该页面包含各种隐藏的m3u8 URL
- 验证扩展是否能正确检测

### 其他常见问题

1. **下载按钮无法点击**
   - 确保本地服务器正在运行
   - 检查服务器地址配置是否正确
   - 查看扩展弹窗中的错误信息

2. **进度显示异常**
   - 检查网络连接
   - 确认yt-dlp工具已正确安装
   - 查看服务器日志

3. **扩展无法加载**
   - 检查Chrome版本是否支持Manifest V3
   - 重新安装扩展
   - 检查权限设置

### 调试步骤

1. 打开Chrome开发者工具 (F12)
2. 切换到Console标签页
3. 查看是否有JavaScript错误
4. 在Network标签页检查API请求状态
5. 检查扩展的错误日志
